# Smart Landing Page Generator

A front-end web application that generates and previews landing page templates for different business categories in real time.

The application allows users to enter business information and instantly visualize how it appears across multiple industry-specific landing page designs.

## Features

- Real-time content updates
- Dynamic business name and description injection
- Multiple landing page templates
- Industry-specific layouts
  - Restaurant
  - Service Business
  - Hotel
- Live preview panel
- Theme switching using JavaScript and CSS
- Template-based architecture

## How It Works

Users provide:

- Business Name
- Business Category
- Business Description

The application automatically updates the selected landing page template and displays a live preview without page reloads.
